# 漫画批量裁边器 (Epub Manga Cutting)

> 🎯 一键批量裁切漫画白边，自动检测黑框，让漫画在阅读器上完美全屏！

---

## 📖 简介

**漫画批量裁边器** 是一款专门为漫画/图像类 EPUB 设计的批量裁切工具。它能自动检测图片中的**黑色边框**或**白色边距**，精准裁切到漫画内容区域，让你的漫画在 Kindle/KOReader/手机等设备上阅读时**无白边、全屏显示**。

## ✨ 主要特性

- 🔍 **智能检测**：先检测黑色边框，再检测白色边距，双重保障
- 📦 **批量处理**：支持同时处理多个 EPUB 文件和图片文件夹
- 📁 **自动扫描**：添加文件夹时自动递归扫描所有子目录中的 EPUB
- 🎛️ **参数可调**：黑框阈值、白边阈值、四方向留白完全可调
- 📊 **进度显示**：实时显示处理进度和详细日志
- 🖥️ **图形界面**：纯 GUI 操作，无需命令行
- 💾 **保留原文件**：输出独立文件，不影响原始文件
- 🚀 **单文件发布**：打包为独立 EXE，无需安装 Python

## 🎯 使用指南

### 基本步骤

1. **添加文件**：点击"添加 EPUB 文件"选择单个文件，或"添加文件夹"批量导入
2. **调整参数**（可选）：
   - **黑框阈值**：检测黑色边框的敏感度（默认 80）
   - **白边阈值**：检测白色边距的敏感度（默认 235）
   - **保留留白**：裁切后四方向额外保留的像素（默认 2px）
3. **选择输出目录**：点击"浏览"选择输出位置（默认桌面/裁切输出）
4. **开始裁切**：点击"开始批量裁切"，等待完成

### 参数说明

| 参数 | 说明 | 默认值 | 调大效果 | 调小效果 |
|------|------|--------|----------|----------|
| **黑框阈值** | 检测黑色边框的灵敏度 | 80 | 检测更宽松 | 检测更严格 |
| **白边阈值** | 检测白色边距的灵敏度 | 235 | 检测更宽松 | 检测更严格 |
| **左/右/上/下留白** | 裁切后保留的边距 | 2 | 保留更多空白 | 裁切更激进 |

### 支持格式

| 格式 | 说明 |
|------|------|
| `.epub` | 直接读取，处理后重新打包 |
| 图片文件夹 | 直接处理文件夹中的图片 |

## 🛠️ 技术原理

1. **黑框检测**：从图片四边向内扫描，找到第一个黑色像素（RGB < 阈值），确定内容边界
2. **白边检测**（备用）：如果未检测到黑框，改为检测白色边距（RGB > 阈值）
3. **自定义留白**：在检测到的边界基础上，额外保留用户指定的边距
4. **批量处理**：解压 EPUB → 裁切所有图片 → 重新打包

## ❓ 常见问题

<details>
<summary><b>为什么我的漫画裁切后还是有很多白边？</b></summary>

1. 检查黑框阈值是否过高（调低试试）
2. 检查是否启用白边检测
3. 部分漫画可能既没有黑框也没有纯白边（如浅灰色背景），可尝试降低白边阈值
</details>

<details>
<summary><b>处理后的 EPUB 在 KOReader 中显示异常？</b></summary>

确保 KOReader 的"页面边距"设置为 0，"缩放模式"设置为"适应宽度"或"适应页面"。
</details>

<details>
<summary><b>可以处理 MOBI 格式吗？</b></summary>

本工具专注于 EPUB 格式。MOBI 需要先用 Calibre 或 KindleUnpack 转换为 EPUB 再处理。
</details>

<details>
<summary><b>EXE 被杀毒软件报毒？</b></summary>

PyInstaller 打包的 EXE 可能被部分杀毒软件误报。这是正常现象，请添加信任或自行从源码运行。
</details>
